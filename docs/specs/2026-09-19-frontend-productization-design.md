# 前端产品化重构设计文档

日期：2026-09-19
范围：web/（Next.js 15 前端），不动引擎与数据层
用户已批准方向 C（视觉 + 信息架构），**附加约束：保留现有配色与字体作为基底，做精致化而非替换**。

## 1. 视觉系统（在现有基底上精致化）

| 项目 | 现状 | 方案 |
|---|---|---|
| 配色 | 靛蓝 accent `#6366f1`、绿/红语义色、CSS 变量双主题 | **保留**，补充缺失 token（hover 态、focus 环、骨架屏色、阴影层级） |
| 字体 | 系统字体栈 | **保留**，仅给所有数字/价格/百分比列加 `font-variant-numeric: tabular-nums`，表格数字等宽对齐 |
| 图标 | emoji（☀/☾/⚠/☁） | 引入 `lucide-react`，统一 SVG 图标（线性、统一笔画） |
| 卡片层级 | panel + card 两层 | 三层：页面背景 → 面板 → 统计卡（细分边框/hover 微光） |
| 动效 | 少量 | 统一 150–250ms ease 过渡、hover 态、focus-visible 环、`prefers-reduced-motion` 降级 |
| 间距 | 大致 8px | 严格 8px 节奏（8/16/24/32），统一卡片内边距 |
| 加载/空态 | 转圈动画 | 骨架屏 shimmer（卡片/表格/图表三种骨架），空状态带引导文案 |

## 2. 信息架构

**导航**：logo + 带图标四入口（仪表盘/交易/信号与持仓/复盘），当前页高亮+图标着色，右侧主题切换（Sun/Moon 图标）+ 数据源状态点（绿点=Supabase，灰点=本地）。

**① 首页 → 今日驾驶舱**（重排主次）：
1. 告警横幅（如有，最顶部）
2. 账户概览：净值曲线（加大到 ~220px）+ 5 个关键数字卡
3. 今日焦点（新增面板）：
   - 今日信号分布（X CALL / Y PUT / Z FLAT，迷你徽章条）
   - 浮亏最多 5 笔持仓（链接到信号页）
   - 3 天内到期持仓倒计时
4. 策略排行（精简表，加实盘状态徽章列）
5. 回测曲线 + 热力图（降层级，放最后）

**② 交易明细**：顶部统计条（筛选结果的笔数/胜率/合计盈亏），数字列等宽。

**③ 信号与持仓**：持仓按策略分组（group header + 小计），信号矩阵保留。

**④ 复盘**：接新 token，曲线图加大，其余不动。

## 3. 技术要点

- 只改 `web/`：`globals.css`（token 扩充）、`layout.jsx`（字体/导航）、`components/`（新增 StatCard / Skeleton / PageHeader / icons）、四个 page.jsx
- 新增依赖：`lucide-react`
- 不动 `lib/data.js`、`engine/`、Supabase
- 验证：无头 Chrome 截图（深色+浅色 × 四页）、`npm run build`、移动宽度 375px 抽查
- 兼容 Quick Reference §1–§3：对比度、focus 可见、hover 反馈、无 emoji 图标、骨架屏 CLS

## 4. 不做（YAGNI）

- 不换配色方案、不换字体家族
- 不加新页面、不改路由结构
- 不动后端/引擎/数据库
- 不做移动端原生适配（仅保证 375px 可读可用）
